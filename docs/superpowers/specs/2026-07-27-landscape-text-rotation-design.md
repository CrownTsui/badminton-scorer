# 横屏文字随设备方向旋转

## 目标

在横屏主方向与反向横屏时，所有可见文字分别随手机方向旋转 90° 与 -90°；面板、背景、边框、按钮尺寸、布局、触控命中区和比赛逻辑保持不变。

## 方案

使用 Screen Orientation API 读取 `screen.orientation.angle`，并同时监听 `screen.orientation` 的 `change` 事件与 `window` 的 `orientationchange` 事件以覆盖常见移动浏览器。

- `90`：为页面添加顺时针文字旋转状态。
- `270`（或 `-90`）：为页面添加逆时针文字旋转状态。
- `0`、`180` 或未知值：清除旋转状态。
- API 不可用或方向值无法识别：维持现有正常显示，不猜测方向。

## 文字范围

静态内容、分数、队名、状态、历史标记、控制按钮、提示文字以及运行时生成的结果/局间弹窗内容均纳入旋转范围。文字以独立的视觉层旋转，DOM 语义、`aria-label` 与事件绑定不变。

## 边界与可访问性

- 仅在横屏视口中应用方向角；切回竖屏立即恢复。
- 不改变键盘快捷键、双击计分、防抖、LocalStorage 或动态弹窗行为。
- 不支持方向 API 的浏览器继续以当前横屏布局显示。
- 不为方向切换增加过渡动画，避免比赛中出现延迟或空间错觉。

## 验证

1. 在 `90°` 横屏验证文字顺时针旋转，非文字元素位置与尺寸不变。
2. 在 `270°` 横屏验证文字逆时针旋转，非文字元素位置与尺寸不变。
3. 竖屏、未知方向与无 API 环境下验证文字正常显示。
4. 验证得分、暂停、重置、局间/赛果弹窗与键盘快捷键不受影响。
